# تمرین محصولات (Product Manager)

یک مینی‌سیستم مدیریت محصولات با استفاده از لیست و دیکشنری در پایتون.

## مفاهیم
- کار با `list` و `dict` (دیتابیس شبیه‌سازی‌شده)
- پیمایش لیست‌ها با حلقه‌ی `for`
- توابع مختلف برای مدیریت محصولات
- گرفتن ورودی از کاربر و اعتبارسنجی اولیه
- کار با فرمت‌بندی اعداد `f"{amount:,}"`

## قابلیت‌ها
- نمایش لیست همه‌ی محصولات
- جستجوی محصول با ID
- نمایش محصولات موجود (stock > 0)
- محاسبه‌ی کل ارزش موجودی انبار
- فیلتر محصولات بر اساس قیمت
- گروه‌بندی محصولات بر اساس دسته‌بندی
- شبیه‌سازی سبد خرید و اعمال تخفیف
