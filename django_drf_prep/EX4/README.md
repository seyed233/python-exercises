# تمرین مدیریت محصولات پیشرفته (Advanced Product Manager)

نسخه‌ی گسترش‌یافته‌ی سیستم مدیریت محصولات با قابلیت‌های جستجو، فیلتر و مرتب‌سازی.

## مفاهیم
- کار با لیست دیکشنری‌ها (شبیه‌سازی جدول دیتابیس)
- جستجو بر اساس کلمات کلیدی (`in` و `lower()`)
- فیلتر کردن بر اساس بازه‌ی قیمت و موجودی
- **مرتب‌سازی با `sorted()`** و استفاده از پارامترهای `key` و `reverse`
- استفاده از `lambda` برای تعریف کلید مرتب‌سازی
- توابع با پارامترهای اختیاری (`None`) برای فیلترهای چندگانه

## قابلیت‌ها
- `search_products`: جستجوی محصولات بر اساس نام
- `filter_by_price`: فیلتر بر اساس حداقل و حداکثر قیمت
- `filter_by_stock`: فیلتر بر اساس حداقل موجودی
- `sort_products`: مرتب‌سازی بر اساس قیمت، نام یا موجودی (صعودی/نزولی)
- `find_products`: جستجوی پیشرفته با ترکیب چند فیلتر به صورت همزمان

## نکته‌ی مهم درباره‌ی `sorted()`
```python
# مرتب‌سازی صعودی بر اساس قیمت
sorted(products, key=lambda p: p["price"])

# مرتب‌سازی نزولی بر اساس موجودی
sorted(products, key=lambda p: p["stock"], reverse=True)
