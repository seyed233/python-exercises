# ex2 — محاسبه‌ی مبلغ سفارش

محاسبه‌ی مبلغ کل سفارش بر اساس کد محصول و تعداد درخواستی.

## مفاهیم
- استفاده از `dict` به عنوان دیتابیس کوچک محصولات
- طراحی تابع با ورودی و خروجی مشخص
- استفاده از `ValueError` برای ورودی نامعتبر
- گرفتن ورودی از کاربر با `input()`

## نکته‌ی امنیتی
قیمت همیشه از دیکشنری `PRODUCTS` خوانده می‌شود — هرگز از ورودی کاربر.
این همان اصل واقعی API است: **قیمت را هرگز از فرانت‌اند نمی‌گیریم.**

## نحوه‌ی اجرا
```bash
python ex2.py
